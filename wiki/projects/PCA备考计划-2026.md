## AWS → GCP 快速映射

| AWS | GCP | 备注 |
|-----|-----|------|
| EC2 | Compute Engine | GCP有自定义机型 |
| S3 | Cloud Storage | 概念几乎一样 |
| RDS | Cloud SQL | 托管关系数据库 |
| DynamoDB | Firestore / Bigtable | Firestore更接近 |
| EKS | GKE | GCP的k8s更原生 |
| Lambda | Cloud Run Functions | |
| ECS/Fargate | Cloud Run | GCP更简洁 |
| VPC | VPC | GCP的VPC是全球资源 |
| IAM | IAM | GCP多了资源层级 |
| CloudWatch | Cloud Monitoring/Logging | |
| CloudFormation | Terraform | GCP官方推Terraform |
