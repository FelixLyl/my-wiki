# 记忆不是功能，而是复利的基础

## 碰撞来源

三篇看似不相干的文章：

- **Andrej Karpathy** 对个人知识库的论断：RAG 每次从零开始，wiki 是复利增长的持久化产物；
- **GBrain** 的核心命题："一个没有 brain-agent loop 的 Agent 永远从零开始；有了此循环，它每天变得更聪明";
- **Hermes Agent** 的崛起：上线不到两个月接近三万 Star，在 AI Agent 框架竞争中快速成为基准线。

## 洞见

**Karpathy 和 Garry Tan 都指向同一个结论：AI 系统的核心竞争力不是"推理能力"，而是"记忆能否持续积累"。** 推理能力是各家模型在快速收敛的商品；而记忆架构一旦建立，差异会随时间复利扩大。

Hermes Agent 的迅速崛起恰好提供了反例的映照。一个开源框架在短期内靠功能对齐快速追上，说明"功能"本身的壁垒极低。但它目前被描述为"值得关注，暂缺深度评测"，核心原因在于**它的记忆与上下文管理方式尚未明确**。框架能否持续分化，取决于是否能在这一维度上建立复利。

GBrain 的 Compiled Truth + Timeline 结构、wiki-compiler 的"每次读取比上次更聪明"，都是同一个设计原则的不同工程实现：**让每次交互留下可被下次交互利用的残留物**。

这与 Karpathy 观察 LLM 编码缺陷时的论断对称：LLM 天然倾向于"静默执行"而非"积累约束"，需要外部机制（CLAUDE.md、brain-loop）把每次交互中获得的理解固化下来，而不是让它随会话消失。

## 推论

AI Agent 框架的真实竞争，发生在三个层次：

1. **功能层**：工具调用、多步推理——这是可被快速复制的，Hermes 的崛起证明了这一点；
2. **集成层**：渠道接入、技能生态——有一定壁垒，但同样可被追赶；
3. **记忆层**：知识如何在交互之间积累、如何溯源、如何复利——这是难以快速复制的。

一个在记忆层有深度设计的框架，与一个没有的框架，差异不体现在第一天，而是在第一年之后。

## 行动意义

对 wiki-compiler 自身而言：做梦机制、幂等入库、`Compiled Truth` 写法，都是在记忆层投资。维护这些机制比追赶任何功能更有战略价值。知识库的价值在于它的不可替代性——这取决于它是否真的在持续积累。
